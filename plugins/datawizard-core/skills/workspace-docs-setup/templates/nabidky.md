# Evidence cenových nabídek

Přehled všech cenových nabídek v projektu. Každá nabídka má číslo **NAB-NNN** (vzestupná řada, nikdy se nerecykluje) a vlastní složku `nabidky/NAB-NNN-kebab-nazev/` s podklady a odhadem developera.

## Workflow

`poptávka` (klient chce něco nacenit) → `odhad` (developer odhaduje náročnost) → `kalkulace` (konzultant počítá cenu) → `odeslána` → `schválena` / `zamítnuta`

## Pravidla

- Nová nabídka = zkopírovat `templates/nabidka/` do `nabidky/NAB-NNN-nazev/`, přidat řádek do tabulky níže.
- Interní ceny a marže zůstávají jen v souborech `*-INTERNI-*` uvnitř složky nabídky — nikdy nesdílet s klientem.
- Finální dokument pro klienta → `04-deliverables/`, sem jen odkaz.
