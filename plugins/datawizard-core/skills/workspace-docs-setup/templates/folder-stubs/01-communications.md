# 01-communications/ — Komunikace, schůzky, e-maily

> **Účel:** Centralizace veškeré komunikace okolo workspace — schůzky, mailové vlákna, slack thready, sw-releases.

## Údržba

Aktualizuj tento soubor když přidáš novou podsložku (nový typ komunikace).

## K čemu složka slouží

Záznam toho, co se kde řeklo, dohodlo, posunulo. Platí: pokud to není napsané tady, nestalo se to.

## Doporučené podsložky

- `01-meetings/` — schůzky (`YYYY-MM-DD-strucny-nazev/` s notes.md, recordings, prep)
- `02-emails/` — důležitá mailová vlákna (export jako .eml nebo .md)
- `03-sw-releases/` — release notes, deploy logy
- `04-slack/` nebo `04-chat/` — důležité thready (export markdown)

## Naming konvence

- Schůzky: `YYYY-MM-DD-strucny-nazev/`
- Release notes: `vX.Y.Z-release.md`
- E-mail vlákna: `YYYY-MM-DD-predmet.md`
