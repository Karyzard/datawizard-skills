# 00-inbox/ — Staging neroztříděných materiálů

> **Účel:** Sem přijde všechno nové, co ještě nemá své místo. Pravidelně procházet a třídit.

## Údržba

Aktualizuj tento soubor když:
- Vznikne nový typ materiálu, který sem chodí pravidelně
- Změní se proces třídění

## K čemu složka slouží

Inbox pro nové materiály před roztříděním do správných složek. Cokoli dorazí (PDF, screenshot, draft, poznámka) → sem, pak roztřídit podle typu.

## Naming konvence

- Datumové prefixy pro chronologické položky: `YYYY-MM-DD-popis`
- Bez prefixu pro nezařazené (zatím)

## Pravidla

- **Pravidelně třídit** — alespoň jednou týdně, nebo při `/sync-docs`
- **Nezůstávat dlouho** — pokud něco leží 30+ dní, je čas rozhodnout (přesunout / archivovat / smazat)
