# 04-deliverables/ — Klientské dodávky

> **Účel:** Dodávkové artefakty pro klienta — co si od nás odnáší.

## Údržba

Aktualizuj tento soubor když přibyde nový typ dodávky.

## K čemu složka slouží

Cokoli, co se předává klientovi: nabídky, specifikace, reporty, finální dokumenty, prezentace.

## Doporučené struktura

- `offers/` — nabídky a smlouvy
- `specs/` — specifikace, scoping dokumenty
- `reports/` — průběžné a finální reporty
- `presentations/` — prezentace pro klienta
- `final/` — read-only finální verze (po podpisu / odsouhlasení)

## Naming konvence

- Verze dokumentu: `YYYY-MM-DD-dokument-vX.Y.md` nebo `dokument-vX.Y.md`
- Finální: přesunout do `final/` s datem podpisu
