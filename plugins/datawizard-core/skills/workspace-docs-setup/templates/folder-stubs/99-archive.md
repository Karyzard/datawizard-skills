# 99-archive/ — Read-only archiv

> **Účel:** Hotové, dokončené, zastaralé. Read-only. Nemazat bez explicitního souhlasu.

## Údržba

Aktualizuj tento soubor když archivuješ něco nového — přidej řádek do „Co je tu archivované".

## K čemu složka slouží

Archiv pro:
- Dokončené projekty / sprinty
- Zastaralé verze dokumentů (po revizi)
- Materiály, které už nepoužíváš, ale chceš je mít pro historickou referenci

## Pravidla

- **Read-only** — neměň obsah, jen přidávej
- **Nemazat** bez explicitního souhlasu majitele workspace
- **Aktualizuj zdroj** — když něco archivuješ, smaž odkaz ze zdrojové složky (CONTEXT.md, AGENTS.md, README.md)
