# 03-context/ — Sdílený produktový kontext

> **Účel:** Vize, principy, design system, branding — věci, které platí napříč celým workspace.

## Údržba

Aktualizuj tento soubor když přibyde nový typ kontextu (nová oblast).

## K čemu složka slouží

Single source of truth pro to, **co produkt je** a **proč existuje**. Když má nový člen pochopit „o čem to celé je", začne tady.

## Doporučené podsložky / soubory

- `vision.md` — produktová vize (proč existujeme)
- `principles.md` — produktové principy (jak rozhodujeme)
- `design-system.md` nebo `design-system/` — barvy, typografie, komponenty
- `branding/` — logo, brand voice, brand assets
- `personas/` — kdo jsou uživatelé
- `glossary.md` — slovník domain pojmů

## Naming konvence

- `kebab-case.md` pro dokumenty
- `kebab-case/` pro vícesouborové oblasti (např. `design-system/`)
