# Delivery

Formát řádku: `- [ ] **D00X** Název — odkaz (od YYYY-MM-DD)`. Blokovaný item dostane ⛔ a důvod.

Index nikdy nesmí ukazovat jinam než složky. Aktualizace indexu je součást commitu, který mění stav itemu.
