# 99-archive

## Účel

Read-only archiv. Věci, které už neplatí, ale je škoda je smazat.

## Pravidla

- Jen přesun dovnitř, nikdy ven a nikdy mazání.
- Archivovaný dokument dostane do frontmatteru `status: archived` a datum archivace.
- Agent tady nemaže nic.
